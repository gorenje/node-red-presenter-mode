# Node-RED version 5 Presenter Mode

## Presenter Mode

Provides an action to remove all navigation and sidebars, leaving only the workspace. 

The action can be bound to a keys stroke for easy access.

- `Presenter Mode Toggle`

See [forum](https://discourse.nodered.org/t/nr5-presenter-mode/101334).

## Sidebar panel navigation

Adds `<` `>` and `X` to the sidebar panels for navigation the sidebar panels and closing them again.

See [forum](https://discourse.nodered.org/t/nr5-add-sidebar-panel-controls/101552).

## Hide right sidebar when searching

Fade out the right sidebar when searching for something. This prevents the side bar from hiding any nodes that might have been found but that are located under the sidebar.

See [forum](https://discourse.nodered.org/t/node-red-5-now-available/101239/91?u=gregorius).

## Scrollbars are hidden after 1.5 seconds of inactivity

The scrollbars are hidden automatically after 1.5 seconds because I don't use them! They come back if the workspace is moved.

See [forum](https://discourse.nodered.org/t/non-transparent-background-needed-for-editor-status-and-horizontal-scroll/101590/5?u=gregorius).
